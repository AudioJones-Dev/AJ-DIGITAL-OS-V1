# Non-Compliant UX Patterns

## Purpose

Name UX patterns that are not acceptable for AJ Digital OS.

## Patterns

- tenant context hidden in a menu only
- approval action without impact explanation
- dashboard metric soup
- disabled button with no explanation when the reason matters
- AI action with no rationale
- loading state with no progress meaning

## Acceptance Criteria

- Reviewers can flag non-compliance consistently.
