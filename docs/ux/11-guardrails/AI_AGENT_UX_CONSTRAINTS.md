# AI Agent UX Constraints

## Purpose

Define the constraints that apply when AI agents influence the UI.

## Constraints

AI agents SHALL:

- respect tenant context
- respect role boundaries
- show rationale for recommendations
- expose approval gates when needed
- preserve auditability

AI agents SHALL NOT:

- invent UI structure from assumptions
- obscure risk
- bypass approval requirements
- hide uncertainty when it affects the outcome

## Acceptance Criteria

- AI-generated UX behavior remains bounded and reviewable.
