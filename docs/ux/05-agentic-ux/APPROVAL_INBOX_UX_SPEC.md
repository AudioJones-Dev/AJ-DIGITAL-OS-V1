# Approval Inbox UX Spec

## Purpose

Define the approval inbox interface.

## Standard

The approval inbox SHALL show:

- requester or agent
- tenant context
- proposed action
- risk level
- reason
- impacted objects
- required decision
- audit history

The inbox SHOULD support:

- approve
- deny
- request clarification
- open audit trail

## Acceptance Criteria

- A reviewer can understand the action without leaving the inbox.
- Approval decisions remain tenant-scoped and auditable.
