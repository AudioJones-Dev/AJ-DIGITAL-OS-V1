# Impact Risk Matrix

## Purpose

Define the user-facing risk scale for agentic actions.

## Matrix

- L0: informational only
- L1: low-impact assistance
- L2: reversible operational change
- L3: client-impacting or approval-gated action
- L4: high-risk or irreversible action

## Acceptance Criteria

- Risk level is visible wherever agent actions are previewed.
- Higher-risk actions require stronger disclosure and approval behavior.
