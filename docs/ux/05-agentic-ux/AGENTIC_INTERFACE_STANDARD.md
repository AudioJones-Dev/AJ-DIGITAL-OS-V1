# Agentic Interface Standard

## Purpose

Define how AI-assisted and agent-driven interfaces should behave.

## Standard

Agentic interfaces SHALL expose:

- intent
- scope
- risk
- rationale
- approval requirement
- execution state
- audit trail

Agentic interfaces SHALL NOT:

- hide client-impacting automation
- conceal irreversible actions
- present generic loading text in place of real status

## Acceptance Criteria

- Users can tell what the agent intends to do.
- Users can tell whether the agent acted, is waiting, or needs approval.
