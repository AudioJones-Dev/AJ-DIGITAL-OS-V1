# AI Status Copy Standard

## Purpose

Define status text for AI and automation states.

## Standard

AI status copy SHALL be specific.

Do not use:

- "working..."
- "processing..."
- "please wait..."

Preferred status copy SHOULD describe:

- what the agent is doing
- what it is waiting on
- whether approval is needed
- whether the result is partial or complete

## Acceptance Criteria

- AI state text tells the user what is happening and what happens next.
