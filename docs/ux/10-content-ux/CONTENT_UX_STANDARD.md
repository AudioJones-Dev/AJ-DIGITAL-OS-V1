# Content UX Standard

## Purpose

Define how content, labels, and explanatory text should behave.

## Standard

Content SHALL be:

- specific
- task-oriented
- non-technical for non-technical users
- consistent across states

Content SHOULD avoid:

- generic filler
- ambiguous system language
- unexplained jargon

## Acceptance Criteria

- A user can understand the action and result from the copy alone.
