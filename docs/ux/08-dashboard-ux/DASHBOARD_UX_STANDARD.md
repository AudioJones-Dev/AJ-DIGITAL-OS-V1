# Dashboard UX Standard

## Purpose

Define how dashboards should work in AJ Digital OS.

## Standard

Dashboards SHALL prioritize signal over noise.

Dashboards SHALL:

- lead with the most important business outcome
- group metrics by decision value
- show tenant scope when relevant
- support drilldown
- avoid cluttered metric dumps

Dashboards SHOULD:

- highlight anomalies, blockers, and next actions
- make the current state obvious at a glance

## Acceptance Criteria

- The dashboard can answer the main operational question quickly.
- Metrics are prioritized rather than dumped in raw form.
