# Dashboard Acceptance Criteria

## Purpose

Define the baseline quality bar for dashboards.

## Criteria

Every dashboard SHALL:

- show tenant scope when relevant
- show the top business outcome first
- have a clear empty state
- have a clear loading state
- have a clear error state
- have a clear permission state when needed
- support drilldown or explanation for key numbers

## Acceptance Criteria

- The dashboard is decision-ready, not decorative.
- Users can understand the state without inspecting implementation details.
