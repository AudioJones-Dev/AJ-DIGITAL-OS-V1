# Role-Specific Requirements

## Purpose

Capture requirements that differ by role.

## Requirements

- Platform admin roles SHOULD see tenant management, audit, and health surfaces.
- Tenant admin roles SHOULD see billing, team, settings, approval, and reporting surfaces.
- Staff roles SHOULD see task-centric and record-centric surfaces.
- Agent roles SHOULD show intent, status, risk, and approval dependencies.

## Acceptance Criteria

- Each role has a documented surface contract.
- Role-specific requirements do not conflict with tenant isolation.
