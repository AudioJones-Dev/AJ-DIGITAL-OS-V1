# Role Visibility Matrix

## Purpose

Map which UI surfaces are visible to which roles.

## Matrix Rules

- Visible means the surface is available and meaningful to the role.
- Hidden means the surface is not discoverable for the role.
- Disabled means the surface is visible but not actionable, with a reason when appropriate.

## Acceptance Criteria

- Each major role can be mapped to the screens it sees.
- No critical safety surface is visible without the correct permission.
