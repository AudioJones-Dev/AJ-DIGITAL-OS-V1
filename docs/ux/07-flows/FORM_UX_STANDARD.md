# Form UX Standard

## Purpose

Define how forms should behave in AJ Digital OS.

## Standard

Forms SHALL:

- validate early and clearly
- preserve user input on recoverable errors
- explain required fields
- show tenant-scoped implications when relevant
- avoid hidden validation failures

Forms SHOULD:

- prevent errors before submission
- separate technical validation from business validation

## Acceptance Criteria

- Users can recover from common form errors without re-entering data.
- Validation messages are specific and actionable.
