# Onboarding Flow Standard

## Purpose

Define the onboarding flow expectations.

## Standard

Onboarding SHOULD:

- establish identity
- establish role
- establish tenant context
- explain permissions
- explain the first useful action

Onboarding SHALL NOT:

- skip tenant selection when tenant-scoped behavior is involved
- bury approval or audit implications

## Acceptance Criteria

- The user knows what tenant and role they are operating under.
- The first task is clear and safe to perform.
