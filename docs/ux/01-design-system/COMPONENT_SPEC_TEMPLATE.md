# Component Spec Template

## Purpose

Use this template for reusable AJ Digital OS component specs.

## Template

```md
# Component Name

## Purpose
## When to Use
## When Not to Use
## Inputs / Props
## States
## Accessibility
## Tenant and Role Behavior
## Approval or Audit Behavior
## Content Rules
## Non-Compliant Patterns
## Acceptance Criteria
## Source References
```

## Acceptance Criteria

- The template captures the full operational context of a component.
- The template is usable by AI coding agents without extra interpretation.
