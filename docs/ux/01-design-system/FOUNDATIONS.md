# Foundations

## Purpose

Document the foundational UX primitives for AJ Digital OS.

## Foundations

- Color SHALL be semantic, not decorative.
- Typography SHOULD support fast scanning and dense operational data.
- Spacing SHALL preserve hierarchy and not flatten important controls.
- Motion SHOULD clarify state changes and not distract from decisions.
- Empty space MAY be used to reduce cognitive load, but not to hide missing content.

## Required States

Every foundation-backed component SHOULD support:

- default
- hover
- focus
- active
- disabled
- loading
- empty
- error
- permission denied

## Acceptance Criteria

- Foundation tokens support operator UI, not just marketing UI.
- Visual semantics align with approval, audit, and tenant-state doctrine.
