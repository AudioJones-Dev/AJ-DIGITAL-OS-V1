# Screen Spec Template

## Purpose

Use this template for every major AJ Digital OS screen.

## Template

```md
# Screen Name

## Purpose
## Audience / Role
## Tenant Context
## Primary Outcome
## Layout
## Data Requirements
## Actions
## States
## Accessibility
## Audit / Approval Behavior
## Empty / Loading / Error / Permission / Partial Success / Agent Active States
## Acceptance Criteria
## Non-Compliant Patterns
## Open Questions
## Source References
```

## Acceptance Criteria

- The screen can be implemented without inventing missing behavior.
- All required states are named in the template.
