# Accessibility Standard

## Purpose

Define the accessibility doctrine for AJ Digital OS UX.

## Standard

Accessibility MUST be treated as architecture.

The interface SHALL target WCAG 2.2 AA.

The interface SHOULD:

- support keyboard-first navigation
- preserve visible focus
- use semantic structure
- avoid color-only meaning
- provide understandable error copy

## Acceptance Criteria

- Accessibility is part of the spec, not a late-stage polish task.
- A screen spec can be reviewed for accessibility before implementation.
