# WCAG 2.2 AA Checklist

## Purpose

Provide a practical checklist for accessibility reviews.

## Checklist

- text has sufficient contrast
- focus is visible
- keyboard navigation works
- labels are programmatic
- headings are structured
- status changes are announced when needed
- error messages are associated with controls
- target sizes are reasonable

## Acceptance Criteria

- The checklist can be used in a review pass without extra interpretation.
