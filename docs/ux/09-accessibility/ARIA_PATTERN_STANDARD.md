# ARIA Pattern Standard

## Purpose

Define semantic and ARIA usage patterns.

## Standard

ARIA SHOULD be used to clarify meaning, not to compensate for poor structure.

Patterns SHOULD include:

- native semantics first
- named controls
- live regions for important status updates
- proper dialog semantics

## Acceptance Criteria

- Assistive tech can interpret the screen state.
- ARIA does not mask a broken document structure.
