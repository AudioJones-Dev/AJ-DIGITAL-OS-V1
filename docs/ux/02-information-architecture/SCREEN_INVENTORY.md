# Screen Inventory

## Purpose

Track the canonical screen set for AJ Digital OS.

## Inventory Rules

Each screen entry SHOULD include:

- screen name
- owner role
- tenant scope
- primary task
- required states
- acceptance criteria

## Baseline Screen Categories

- dashboard
- tenant switcher
- approval inbox
- audit trail
- agent detail
- workflow detail
- contact or client detail
- report or KPI view
- settings and access management

## Acceptance Criteria

- The inventory can be used as a build backlog.
- Every major screen category maps to a role and a tenant context.
