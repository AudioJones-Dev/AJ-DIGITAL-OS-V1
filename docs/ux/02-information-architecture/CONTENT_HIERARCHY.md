# Content Hierarchy

## Purpose

Define how content priority should be ordered in AJ Digital OS screens.

## Hierarchy

1. Safety and scope
2. Current status
3. Primary action
4. Important evidence
5. Supporting details
6. Secondary metadata

## Rules

- Tenant context and approval state MUST outrank decorative content.
- Metrics MUST be grouped by business significance, not by data source order.
- Warnings and blockers SHOULD be visible before tertiary details.

## Acceptance Criteria

- The most important decision is visible without scrolling in common cases.
- The hierarchy supports fast comprehension under operational pressure.
