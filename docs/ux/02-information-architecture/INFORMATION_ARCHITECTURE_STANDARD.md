# Information Architecture Standard

## Purpose

Define the information-architecture rules for AJ Digital OS interfaces.

## Standard

Information architecture SHALL:

- reflect tenant boundaries
- reflect role boundaries
- reflect task priority
- support progressive disclosure
- keep approval and audit surfaces discoverable
- keep dashboard hierarchy obvious

Information architecture SHOULD:

- keep primary actions near the work they affect
- minimize navigation ambiguity
- separate administrative surfaces from client-facing surfaces

## Acceptance Criteria

- The navigation model is understandable from the spec alone.
- Important objects are discoverable by role and tenant.
- The IA supports both operator workflows and client workflows.
