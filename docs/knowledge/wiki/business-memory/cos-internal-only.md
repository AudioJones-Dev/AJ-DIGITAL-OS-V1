# Decision: COS Is Internal-Only

## Decision

The Cognitive Operating System name is internal-only during the Business Memory pilot.

## Alternatives Considered

- Use COS publicly now.
- Avoid naming the model at all.
- Keep COS internal until retrieval and decision value are proven.

## Rationale

The internal model is useful for organizing cognition, but public use could create premature positioning before the pilot proves practical value.

## Tradeoffs

Internal naming improves coordination. Holding the name back publicly avoids marketing drift and premature canonization.
