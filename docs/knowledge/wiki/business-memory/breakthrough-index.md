# Knowledge: Breakthrough Index

## Purpose

This index preserves the major working breakthroughs from the 2026-07-05 AJ Digital / Audio Jones session.

`Breakthrough` is a candidate note type only. It is not part of the approved Business Memory ontology during the pilot.

## Candidate Breakthrough Definition

A breakthrough is a realization that permanently changes multiple downstream systems, products, decisions, or beliefs.

Breakthroughs should be rare. A breakthrough should record previous belief, new belief, trigger, evidence, downstream impact, open questions, and ratification status.

### Previous Belief

### New Working Belief

The system should model how observations become knowledge, doctrine, architecture, decisions, execution, feedback, and learning.

### Trigger

The discovery process showed that AJ Digital's core issue was semantic and cognitive organization, not document volume.

### Why It Matters

It reframes Obsidian as an interface, Git as audit, AI memory as retrieval context, and lifecycle as upstream of folder structure.

### Downstream Impact

#### Brand

Supports a deeper internal positioning around founder reasoning and organizational memory.

#### Sales

Changes discovery from "do you need AI?" to "where does your business lose memory, judgment, or execution consistency?"

#### Marketing

Requires simpler public translation.

#### Documentation

#### AI Agent Behavior

More structure could create overhead before value is proven.

### Ratification Status
