# Principle: Structure Is Transferable; Domain Validation Remains Required

## Principle

Reusable structure can transfer across domains, but each domain still requires validation against its own reality.

## Meaning

Frameworks, templates, and operating models can create leverage, but they do not eliminate the need to test assumptions against the specific business, client, market, or workflow.

## Evidence Base

This is a working pilot principle from Audio's first-note list. It needs domain-specific examples before promotion.

## Scope

Business Memory, diagnostics, frameworks, client strategy, and implementation planning.

## Failure Mode

If structure is treated as proof, the system may overgeneralize from one domain and produce confident but invalid recommendations.
